# Field Photo Prep

Android app for taking field-work photos and sending them to the correct Google Drive work folder while keeping the app itself lightweight.

Initial Drive structure:

```text
Master folder
└── Address
    └── Work Order - YYYY-MM-DD
        └── Photos
```

Example:

```text
HNP
└── 1607 Crestview Drive
    ├── Cut Grass - 2026-09-06
    └── Winterization - 2026-11-15
```
